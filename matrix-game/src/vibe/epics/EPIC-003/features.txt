This player page game loop complements the iPad gameplay loop. The iPad controls the category, scales, secret number, and turn order. The Player page is where each player makes guesses, reveals their own answer, enters the correct secret number after it is revealed on the iPad, and scores points.

This feature only affects the normal Player page and related player-facing state.

Do not change the iPad gameplay loop unless absolutely required.

Important:

- The Player page should use the language selected on the Start page.
- The Player page should use the difficulty selected on the Start page.
- The matrix size on the Player page should match the selected difficulty.
- The Player page does not need categories, scales, or secret number generation.
- The Player page only needs a number matrix matching the difficulty.
- Scores only need to exist during the current browser session for now.
- Scores do not need to persist after refresh.

Scoring rules for normal guessing turn:

Compare the player's selected guess with the correct secret number entered after the iPad reveal.

- If the selected guess is exactly the correct secret number, award 3 points.
- If the selected guess is in the same row or same column as the correct secret number, award 1 point.
- Otherwise, award 0 points.

Important scoring priority:

- Exact match should score 3 points, not 1 point.
- Same row or same column only scores 1 point if it is not an exact match.

Row and column calculation:

The row and column depend on the matrix size.

For a matrix size of N:

- row = Math.floor((number - 1) / N)
- column = (number - 1) % N

Examples for a 3x3 matrix:

- 1 is row 0, column 0.
- 2 is row 0, column 1.
- 4 is row 1, column 0.
- 9 is row 2, column 2.

- Return to the Start Turn stage.
- The running score should remain.
- Display the running score somewhere simple on the Player page for testing.
